# Forever Classic UI

Restyles World of Warcraft Forever's HUD to look like Classic. Player, target, focus, pet, party, cast bars, and the minimap keep Blizzard's frames and swap in Classic art, size, and chrome.

Open **HUD Edit Mode** (or `/fcui options`) and use the Classic UI checkboxes to enable each skin:

- Player Frame
- Target and Focus
- Pet Frame
- Party Frames
- Cast Bar
- Minimap

## Commands

| Command | What it does |
| --- | --- |
| `/fcui` | Help |
| `/fcui options` | Open HUD Edit Mode |
| `/fcui status` | Show which skins are enabled |
| `/fcui reset` | Restore default settings |
